# LinguaPDF Translator

Design and build a modern premium SaaS landing page for an AI-powered PDF translation platform called **LinguaPDF**.

## Product
LinguaPDF transforms English PDF documents into accurate Indonesian PDFs while preserving the document structure, paragraphs, tables, formatting, and layout as much as possible.

Core flow:
PDF Upload → Document Analysis → AI Translation → Layout Reconstruction → Translated PDF

## Visual Direction
Create a sophisticated, minimal, premium SaaS aesthetic.

Reference feeling:
- modern AI productivity software
- Apple-like simplicity
- Linear / Notion / Raycast level of polish
- clean white/off-white background
- subtle gray borders
- soft shadows
- elegant typography
- restrained blue/indigo accent
- lots of whitespace
- realistic UI mockups
- absolutely no generic "AI futuristic" visuals
- no excessive gradients
- no neon
- no robotic illustrations
- no excessive glassmorphism
- no stock photos

The website should feel like a real startup product that could be launched publicly.
